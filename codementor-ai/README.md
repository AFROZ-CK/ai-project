# 🧠 CodeMentor AI

An AI-powered code review and mentoring platform that helps developers write better code, understand best practices, and learn from mistakes. Built with React, FastAPI, and CodeBERT.

## 🚀 Features

- **AI Code Review** – Automated code review with line-by-line suggestions
- **Bug Detection** – Identify potential bugs before they hit production
- **Security Scanner** – OWASP-based vulnerability detection
- **Performance Optimizer** – Suggest performance improvements with benchmarks
- **Code Explanation** – AI explains complex code in plain English
- **Auto-Documentation** – Generate JSDoc/docstrings automatically
- **Refactoring Suggestions** – Convert code to modern patterns
- **Learning Mode** – Educational explanations with linked documentation
- **Multi-language Support** – Python, JavaScript, TypeScript, Java, Go, Rust

## 🏗️ Tech Stack

### Frontend
- **React 18** + TypeScript
- **Monaco Editor** (VSCode editor in browser)
- **Tailwind CSS** + shadcn/ui
- **React Query** for async state

### Backend
- **FastAPI** + Python 3.11
- **OpenAI GPT-4** for code analysis
- **CodeBERT** (HuggingFace) for code understanding
- **Tree-sitter** for syntax parsing
- **PostgreSQL** + Redis

## 🌐 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/review` | Full AI code review |
| POST | `/api/explain` | Explain code snippet |
| POST | `/api/optimize` | Performance optimization |
| POST | `/api/security/scan` | Security vulnerability scan |
| POST | `/api/document` | Auto-generate documentation |
| POST | `/api/refactor` | Suggest refactoring |
| POST | `/api/chat` | Chat with code context |

## 🎯 Code Review Categories

- 🐛 **Bugs** – Logic errors, edge cases, null checks
- 🔒 **Security** – SQL injection, XSS, hardcoded secrets
- ⚡ **Performance** – N+1 queries, memory leaks, algorithm complexity
- 📖 **Readability** – Naming conventions, code structure, comments
- ✅ **Best Practices** – Design patterns, SOLID principles
- 🧪 **Testability** – Suggests unit test cases
