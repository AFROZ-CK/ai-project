## 1. 🧠 AI Resume Builder

**Problem:** Job seekers struggle to create ATS-optimized resumes that stand out.

**Solution:** GPT-4 powered resume generator that creates tailored, ATS-optimized resumes and rewrites them for specific job descriptions.

**Key Features:**
- GPT-4 generates professional summaries and enhances experience bullets
- ATS keyword optimization with job description matching
- 10+ professional templates with live PDF preview
- Cover letter generation

**Tech Stack:** React 18 + TypeScript, FastAPI, PostgreSQL, OpenAI GPT-4, Redis, AWS S3

📁 [`/ai-resume-builder`](./ai-resume-builder)

---

## 2. 🎤 Smart Interview Coach

**Problem:** Students and freshers have no way to practice interviews with real feedback.

**Solution:** AI-powered mock interview platform with voice recording, Whisper transcription, and GPT-4 feedback on every answer.

**Key Features:**
- Role-specific AI question generation (SWE, Data, PM, Finance)
- Voice recording + OpenAI Whisper transcription
- Real-time GPT-4 feedback on STAR structure, content, clarity
- Session-based progress tracking with improvement dashboard
- WebSocket-based real-time interview flow

**Tech Stack:** Next.js 14, Node.js + Socket.io, MongoDB, OpenAI GPT-4 + Whisper

📁 [`/smart-interview-coach`](./smart-interview-coach)

---

## 3. 🏥 MediAI Health Assistant

**Problem:** People often don't know when to seek medical attention or what their symptoms might mean.

**Solution:** AI health assistant powered by Google Gemini that analyzes symptoms, checks drug interactions, and provides evidence-based health information.

**Key Features:**
- Symptom analysis with urgency triage (routine/urgent/emergency)
- Drug interaction checker with severity ratings
- Natural language medical Q&A with Gemini Pro
- Emergency first-aid guidance
- PWA with offline capability

**Tech Stack:** React 18 + PWA, Flask, PostgreSQL, Google Gemini Pro

📁 [`/mediai-health`](./mediai-health)

## 4. 🔍 CodeMentor AI

**Problem:** Developers, especially students, lack access to senior code review mentorship.

**Solution:** AI code review platform that analyzes code for bugs, security vulnerabilities, performance issues, and provides educational explanations.

**Key Features:**
- Comprehensive AI code review (bugs, security, performance, style)
- OWASP security vulnerability scanner
- Code explanation in plain English for learning
- Auto-documentation generator (JSDoc, Python docstrings)
- Monaco Editor (VSCode-like) in browser
- Multi-language: Python, JS, TS, Java, Go, Rust

**Tech Stack:** React 18 + Monaco Editor, FastAPI, OpenAI GPT-4, CodeBERT

📁 [`/codementor-ai`](./codementor-ai)

---

## 5. 📈 AI Stock Predictor Dashboard

**Problem:** Retail investors lack access to sophisticated AI-powered market analysis tools.

**Solution:** Stock prediction dashboard using Bidirectional LSTM + sentiment analysis to forecast prices and generate AI market summaries.

**Key Features:**
- Bidirectional LSTM with 24 technical indicators for price prediction
- Real-time news sentiment analysis
- Interactive TradingView-style charts with prediction overlay
- Portfolio tracker with real-time P&L
- AI-generated daily market briefing
- Backtesting engine for trading strategies

**Tech Stack:** Next.js 14, FastAPI, TensorFlow/Keras LSTM, yfinance, OpenAI GPT-4

📁 [`/ai-stock-predictor`](./ai-stock-predictor)
